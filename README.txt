QUTTY Website — HTML/CSS/JavaScript
=================================

Никаких установок, npm и сервера для макета не нужно.

1. Распакуйте архив в отдельную папку.
2. Откройте index.html двойным щелчком в браузере.
3. Откройте эту же папку в VS Code для редактирования.

Страницы:
index.html — главная
features.html — возможности
download.html — скачивание
updates.html — обновления
news.html — новости
roadmap.html — планы разработки
about.html — о проекте
team.html — команда
support.html — поддержка
faq.html — частые вопросы
donate.html — поддержать проект
privacy.html — ПУСТАЯ страница политики конфиденциальности

css/style.css — все стили
js/script.js — содержимое страниц, общее меню, подвал, переключение темы, мобильное меню

Контент страницы задаётся свойством data-page в HTML и функцией с этим именем
в объекте pages в js/script.js.

Контактная почта указана в js/script.js:
email: 'quttyhelp@gmail.com'

ВАЖНО: Это макет. Нет авторизации, базы данных, онлайн-переписки, платежей,
готовых загрузок, серверных форм и сохранения учётных данных.
Только выбранная тема сохраняется локально в браузере.
Для последующей авторизации нужна серверная часть (например, Python + SQLite)
с проверкой паролей, авторизацией, безопасной передачей и хранением данных.
Не храните пользовательские пароли в JS или localStorage.

Имена и роли команды перед публикацией сайта нужно согласовать с участниками.
Юридические документы перед запуском должны быть заполнены и проверены.
